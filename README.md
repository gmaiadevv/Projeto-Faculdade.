# 🛒 Sistema de Mercado — Java

Sistema de mercado desenvolvido durante o **1º semestre de Ciência da Computação**, com o objetivo de aplicar na prática os conhecimentos adquiridos em **lógica de programação e desenvolvimento em Java**.

O projeto simula o funcionamento básico de um mercado, permitindo realizar **cadastro e gerenciamento de produtos e pessoas**, além de outras operações relacionadas ao funcionamento do estabelecimento.

## 📌 Sobre o Projeto

O sistema foi desenvolvido como um projeto acadêmico para colocar em prática conceitos fundamentais da programação.

A aplicação funciona por meio de um sistema interativo, onde o usuário pode navegar pelas opções disponíveis e realizar diferentes operações dentro do mercado.

### 🧑‍💻 Principais funcionalidades

* 👤 Cadastro de pessoas/clientes
* 📦 Cadastro de produtos
* 🔎 Consulta de produtos e cadastros
* ✏️ Gerenciamento de informações
* 🛒 Operações relacionadas às compras
* 📊 Controle básico de produtos
* 💾 Armazenamento e leitura de informações
* 🖥️ Interface executada pelo terminal

## 🛠️ Tecnologias utilizadas

| Tecnologia               | Utilização                           |
| ------------------------ | ------------------------------------ |
| ☕ Java                   | Desenvolvimento da aplicação         |
| 📄 CSV                   | Armazenamento de informações         |

Durante o desenvolvimento foram utilizados conceitos fundamentais estudados no primeiro semestre, como:

* Métodos
* Arrays e `ArrayList`

* Manipulação de arquivos

## 🎯 Objetivo

O principal objetivo foi transformar os conhecimentos teóricos aprendidos em sala de aula em uma aplicação funcional.

Mais do que criar um sistema de mercado, o projeto serviu como uma oportunidade para compreender melhor como diferentes conceitos de programação podem ser utilizados juntos na construção de uma aplicação.

## 🚀 Aprendizados

Com esse projeto, pude desenvolver minha experiência com **Java**, principalmente na criação de classes, manipulação de dados, estruturas de controle e organização de um sistema maior.

Também foi uma das primeiras experiências trabalhando com um projeto que possui diferentes funcionalidades e classes interligadas.
